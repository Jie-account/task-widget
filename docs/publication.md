# 公开维护说明

本仓库提供应用源码、产品规则、通用构建步骤、示例线框和脱敏后的验证结论。

## 公开整理范围

2026-11-03清理了文档和历史版本中的本机绝对路径、私人经验库链接、会话UUID及实际任务／页面记录。原始会话、设备截图、个人备份和旧仓库保留在私有归档。公开仓库采用独立仓库对象存储，避免旧提交对象随仓库可见性变化而公开。

保留了代码迭代历史、R／E／T编号和必要技术结论。提交身份使用GitHub隐藏邮箱；APK中的签名证书及校验值属于公开验证信息，私钥保存在仓库之外。

v0.3.0的程序源码与APK保持原值，文档和发布附件已按公开范围整理。公开后已验证源码与四附件可匿名访问、下载散列一致，原私有归档及旧提交无法匿名访问。历史提交与标签标识因此变化，已有旧克隆应重新克隆公开仓库，使用新的历史继续工作。

## 后续维护

- 构建步骤使用环境变量和仓库相对路径；本机SDK、缓存和配置放在忽略目录。
- 测试使用独立示例；共享截图前移除桌面、通知和任务正文中的私人信息。
- 备份JSON包含完整任务内容，通过私人渠道保管；对外复现时使用虚构样例。
- 发布前核对源码、提交历史、Release正文及附件；发布包只包含APK、通用说明和校验材料。
- 密钥、访问令牌、个人备份和设备原始材料保存在Git之外；维护新的忽略规则时同步检查历史。
