# T-011 组件末页新建表验证

- 执行：S-002，2026-11-11；设备：P60／HarmonyOS4.2.0／API31／华为自带桌面。
- 验证包：正式release变体0.3.1／code9，与待发布APK相同；从0.3-local同签名覆盖安装。
- 依据：[R77](../requirements.md)、[交互说明v0.7](../wireframes.md)。

## 1. 新功能与必要回归

| 检查面 | 实际结果 |
|---|---|
| 入口与作用域 | 表标签最后一页显示新建表“＋”，其他页隐藏；有日期、无日期、已完成均可进入，已完成仍不提供添加任务 |
| 直接编辑 | 点击“＋”直接打开新建表名输入页，空名及重复名提示并保留输入 |
| 取消与草稿 | 空输入返回、未保存退出、取消退出保留草稿、确认放弃返回桌面通过；再次导出与原数据一致 |
| 创建与跨页 | 新表追加末尾，保存返回桌面并选中新表；跨页时显示新表所在标签页，沿用原子表视图 |
| 原有表管理 | App入口可新建和改名，保存仍返回管理表；App选择保持原值 |
| 共用任务流程 | 在独立测试表中新增任务、保存返回组件、重开详情读取通过 |
| 原记录保护 | 测试期间导出核对，原表与任务全部字段及相对顺序保持，增加的均为独立测试记录 |

回归聚焦共用表名编辑器、仓储提交、组件返回、原有任务入口和本次数据恢复。此前用电与自动过期的人工验收结论沿用；E15–E17继续保留为后续方向。

## 2. 旧版数据恢复

安装前通过旧版实际导出JSON，并与私有快照比对。覆盖安装后再导出，全部业务和App选择保持。

功能验证通过后，使用新版系统文件选择器选取安装前的真实JSON备份，确认整体恢复，再次导出比对：全部表、任务、日期精度、状态、排序、sequence及App选择与原备份完全一致，测试表和任务全部清除。组件恢复原表／视图，原实例保留。

手机保留安装前与恢复后的备份；中间测试导出文件已清理。私人任务、文件内容、实例记录及截图仅留本机忽略目录`.tools/device/t011/`。
