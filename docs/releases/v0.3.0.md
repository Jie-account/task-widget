# 任务组件 v0.3.0

面向个人使用的首个正式版本，以可调整大小的桌面组件记录任务。首版验收已完成，优先使用环境为华为P60／HarmonyOS 4.2.0／自带桌面。

## 功能

- 默认4×4组件，长按后可拖动边框调整大小；固定表标签与视图栏，任务列表滚动。
- 表管理，以及有日期、无日期、已完成三个视图；任务新增、编辑、完成、恢复、取消日期与删除。
- 可选年月日或具体时分，按日期排序，过期未完成任务标题变红。
- 表与无日期任务支持长按拖拽：表松手即保存，任务排序点“保存排序”提交。
- App与组件统一黑色背景和符号大小，菜单在按钮下方展开，确认弹窗统一“取消／确认”。
- 首页“⋯”提供JSON导出与导入；导出全部表、任务和排序，导入展示数量并确认后整体覆盖当前数据。本机组件实例保留。恢复前可先导出当前记录。

## 下载与安装

下载 `task-widget-0.3.0.apk`，传到手机后按系统提示安装；`task-widget-0.3.0.zip`包含同一APK、使用说明和SHA256校验文件。

沿用原型应用标识和本机签名，已有安装可直接覆盖升级，保留任务和桌面组件。首次打开后通过顶部“⋯ → 添加组件”添加，或从桌面小组件列表选择“任务组件”。详细操作见[使用说明](https://github.com/Jie-account/task-widget/blob/v0.3.0/docs/user-guide.md)。
