# 任务组件 v0.3.1

组件新增快捷新建表：翻到表标签最后一页，点击表标签右侧“＋”直接填写表名。保存后，新表追加到末尾，返回桌面并自动选中新表、显示其标签所在页，保留原子表视图。

空名、重复名与未保存退出沿用现有提示；有日期、无日期和已完成视图均可新建表。App表管理继续提供新建、改名、拖拽和删除。

## 下载与升级

下载`task-widget-0.3.1.apk`，按手机提示覆盖安装；也可下载包含APK、`USER_GUIDE.md`及`SHA256SUMS.txt`的ZIP。沿用原应用标识和签名，已有数据和桌面组件保留。

需要转移记录时，通过首页“⋯”导出JSON，在新版导入；确认后整体覆盖当前数据。操作见[使用说明](https://github.com/Jie-account/task-widget/blob/v0.3.1/docs/user-guide.md)。
