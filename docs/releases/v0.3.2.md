# 任务组件 v0.3.2

点击任意橙色日期，可在年月日与“几天后／今天／几天前”之间双向切换；App和桌面组件的所有表同步，并记住本机选择。相对天数按自然日计算，过期仍按原日期及时分判断。

取消日期移到详情“修改日期”右侧。点击仅清空当前草稿的年月日及时分，与标题、描述一起保存后生效；未保存退出可继续编辑或放弃。详情始终保留真实日期精度。

组件集合按表、视图、日期模式及当天日期区分缓存，改善切换后沿用旧行的问题；相对模式增加每日午夜刷新安排。

## 下载与升级

下载`task-widget-0.3.2.apk`覆盖安装，或下载包含APK、`USER_GUIDE.md`、`SHA256SUMS.txt`的ZIP。应用标识和签名沿用，保留原任务、表、顺序和桌面组件。

备份仍采用原JSON格式，保存真实日期；导入确认后整体覆盖业务数据，沿用本机日期显示偏好。操作见[使用说明](https://github.com/Jie-account/task-widget/blob/v0.3.2/docs/user-guide.md)。
