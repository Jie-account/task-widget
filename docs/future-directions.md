# 后续扩展方向

- 文档版本：v0.4
- 更新日期：2026-10-28
- 当前首版范围见[需求](requirements.md)，实际执行安排统一见[任务清单](progress.md)。
- 本文保留扩展候选和需要讨论的问题；启用某项时，将确认规则写回需求，安排写入任务清单。

## 1. 用户明确暂缓

| 编号 | 方向 | 未来需要讨论 |
|---|---|---|
| E01 | 手动导出与导入 | 格式、范围、合并或覆盖、去重、排序与状态保留、版本兼容 |
| E02 | 备份与设备迁移 | 手动或自动、位置、保留数量、恢复与版本迁移 |
| E03 | 回收站或删除恢复 | 保留期、表与任务关系、永久删除、状态和顺序恢复 |
| E04 | 操作撤销 | 操作范围、撤销窗口、连续操作与确认流程 |
| E12 | 多组件独立使用 | 各实例独立选择表与子表，共享任务数据 |
| E13 | 更多组件尺寸 | 半页、小尺寸、横屏或平板；当前一页布局仍按实际可用区域适配 |

任务完成后恢复为未完成属于首版。暂缓备份与删除恢复期间，基础本地保存以及已有操作确认继续保留。

## 2. 首版边界与后续兼容意向

| 编号 | 方向 | 状态 |
|---|---|---|
| E05 | 任务跨表移动 | 用户明确首版不实现，未来按需重新讨论 |
| E14 | 小米等其他安卓系统 | 用户已认可标准 Android 路线和分阶段验证；具体型号/系统版本待后续确定，当前未实测 |

兼容设计与验证条件集中在[技术方向第 4、5 节](technical-direction.md)。

## 3. 尚未要求的候选

| 编号 | 方向 | 需要考虑 |
|---|---|---|
| E06 | 提醒与通知 | 权限、准确性、省电、与截止日期的关系 |
| E07 | 重复任务 | 规则、下一次生成、过期与历史 |
| E08 | 云同步与多设备 | 账号、冲突、离线、删除传播、服务成本 |
| E09 | 丰富任务内容 | 附件、链接、标签、子任务、搜索与筛选 |
| E10 | 外观与组件样式 | 主题、颜色、字号、更多布局 |
| E11 | 批量操作 | 多选完成、删除、日期调整和确认 |

## 4. 实施时采用的扩展基础

稳定标识、日期精度、状态和排序信息、数据迁移及适度职责分离见[技术方向第 1 节](technical-direction.md)。具体存储实现随工程方案确定。
