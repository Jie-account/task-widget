# 任务组件使用说明

当前候选版本为 **0.2.1-local**，已安装到华为 P60；自然跨零点和省电锁屏隔夜观察仍在进行，结果见[T-006 验收](verification/t006-p60.md)。

## 1. 安装与添加组件

本机留存包位于 `dist/task-widget-0.2.1-local/`，其中 APK 与手机当前安装版本相同。将 APK 传到手机，打开后按系统提示安装；已有版本选择覆盖安装，数据与组件继续保留。首版没有备份、导入或恢复功能，卸载或清除应用数据会移除本地记录。

打开“任务组件”，点“添加组件”，按桌面提示确认；也可以在桌面的小组件列表选择“任务组件”。默认采用 4×4 大小。长按组件，出现边框后拖动圆点调节大小，点外部结束；可调范围由手机桌面决定。

## 2. 日常记录

组件顶部切换表，左右箭头翻阅其他表标签；下面切换“有日期”“无日期”“已完成”。列表上下滑动，顶部保持固定。

- 在“有日期”或“无日期”点 **＋** 添加任务。标题必填，描述可留空；前者默认今天，后者默认没有日期。
- 点任务标题打开详情，改好后点“保存”。从组件打开时保存回桌面，从 App 打开时回 App；修改未保存时返回会提示放弃或继续编辑。
- 点“设置日期／修改日期”，填写年月日，需要具体时刻时开启时分并填全。先“确认日期”返回草稿，再“保存”任务才生效。过去日期可以使用。
- 点方框并确认，任务进入“已完成”；在“已完成”点勾选框并确认可恢复，原日期保留。
- 点橙色日期并确认，取消日期，任务移到“无日期”最上方。点 **×** 并确认会删除任务。

“有日期”按日期和时刻从早到晚排列，仅日期任务排在当天定时任务之后；超过时刻或仅日期任务跨到次日时，未完成标题变红。后台刷新可能受系统省电影响而延迟，打开 App 会重新计算显示。

“无日期”的 **⋯ → 修改排序** 可调整顺序并保存；新任务、取消日期和恢复的无日期任务放在最上方。“已完成”按最近完成在前排列；另外两个子表的菜单当前显示空操作说明。

## 3. 管理表

打开 App，点“表管理”，可以新建、改名、上下移动和删除表。始终至少保留一张表；删除表前会显示表名与任务总数，确认后连同所属任务一起删除。

首版任务固定归属创建时的表。跨表移动、备份、删除恢复和多组件独立使用见[扩展方向](future-directions.md)。

## 4. 当前使用条件

当前按 P60 默认字号、竖屏、正常系统时间和单组件场景使用。大字体、屏幕旋转与草稿恢复、系统日期／时区设置改变的专项验证已按用户决定列入后续方向。

本地留存 APK 使用当前原型签名，用于个人覆盖安装；后续更新继续保持应用标识和签名一致。包内提供 SHA256 校验文件，构建复现和代码入口见[开发文档](development.md)。
