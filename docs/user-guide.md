# 任务组件使用说明

当前版本为 **v0.3.1**，组件末页新建表及必要回归已完成P60验证，旧版数据已导入并核对完整，见[T-011记录](verification/t011-p60.md)。首版用电与自动过期结论见[T-006](verification/t006-p60.md#10-最终人工验收与首版收尾)。

## 1. 安装与添加组件

从 [GitHub Release](https://github.com/Jie-account/task-widget/releases/tag/v0.3.1) 下载 `task-widget-0.3.1.apk`，或下载包含APK、说明和校验文件的ZIP。将APK传到手机，打开后按系统提示安装；已有原型可直接覆盖升级，数据与组件继续保留。需要卸载或清除数据时，先通过下文JSON导出保存当前记录。

打开“任务组件”，点顶部 **⋯ → 添加组件**，按桌面提示确认；也可以在桌面小组件列表选择“任务组件”。默认采用 4×4 大小。长按组件，出现边框后拖动圆点调节大小，点外部结束；可调范围由手机桌面决定。

## 2. 日常记录

组件顶部切换表，左右箭头翻阅其他表标签；下面切换“有日期”“无日期”“已完成”。列表上下滑动，顶部保持固定。

- 在“有日期”或“无日期”点 **＋** 添加任务。标题必填，描述可留空；前者默认今天，后者默认没有日期。
- 点任务标题打开详情，改好后点“保存”。从组件打开时保存回桌面，从 App 打开时回 App；修改未保存时返回会提示，点“取消”继续编辑，点“确认”放弃并退出。
- 详情中显示“所属表：表名”。仅日期显示年月日，设置了时分则同时显示；未设日期时显示“未设置日期”。
- 点“设置日期／修改日期”，填写年月日，需要具体时刻时开启时分并填全。先“确认日期”返回草稿，再“保存”任务才生效。过去日期可以使用。
- 点方框并确认，任务进入“已完成”；在“已完成”点勾选框并确认可恢复，原日期保留。
- 点橙色日期并确认，取消日期，任务移到“无日期”最上方。删除任务统一使用列表中的 **×**，查看弹窗说明后确认。

“有日期”按日期和时刻从早到晚排列，仅日期任务排在当天定时任务之后；超过时刻或仅日期任务跨到次日时，未完成标题变红。后台刷新可能受系统省电影响而延迟，打开 App 会重新计算显示。

“无日期”的 **⋯ → 修改排序** 中长按行或 **≡** 标记，拖到目标位置，点“保存排序”提交。拖至列表边缘可继续滚动；未保存退出会提示。新任务、取消日期和恢复的无日期任务放在最上方。“已完成”按最近完成在前排列；另外两个子表的菜单显示暂无操作说明。

菜单在 **⋯** 下方展开，点菜单外任何位置关闭；点菜单项执行对应功能。App 顶部的 **⋯** 是功能菜单，子表行的 **⋯** 只处理当前子表。

确认操作显示居中弹窗，后方保留原桌面或 App 页面。底部统一为“取消”和红字“确认”，操作内容由标题和正文说明；点取消或系统返回可取消操作。

有日期／无日期列表为空时显示“点击右上方+添加任务”，已完成列表为空时显示“当前没有已完成任务”。

## 3. 管理表

打开App，点顶部 **⋯ → 表管理**，可以新建、改名、长按拖拽排序和删除表。表拖到目标位置后松手即保存；列表只显示表名和操作。始终至少保留一张表；删除表前显示表名与任务总数，确认后连同所属任务一起删除。

翻到组件表标签的最后一页，点表标签右侧“＋”直接新建表。填写表名并保存后返回桌面，组件选中追加在末尾的新表并显示其标签所在页；原子表视图保留。取消或放弃未保存内容时返回桌面，原表与选择保持。空名或重复名会提示修改。

任务固定归属创建时的表。跨表移动、自动备份、删除恢复和多组件独立使用见[扩展方向](future-directions.md)。

## 4. JSON导入与导出

顶部 **⋯ → 导出 JSON**，在系统文件页面选保存位置和文件名。文件包含全部表、任务、日期、完成状态和排序。

顶部 **⋯ → 导入 JSON**，选本App导出的备份，查看表／任务数量与覆盖说明，点“确认”整体恢复；当前业务数据会替换为该备份。取消选择、取消确认或无效文件均保留当前数据。

恢复前可先导出当前记录，保留一份可回退的备份。格式细节按需见[JSON说明](json-backup.md)。

## 5. 当前使用条件

当前按 P60 默认字号、竖屏、正常系统时间和单组件场景使用。大字体、屏幕旋转与草稿恢复、系统日期／时区设置改变的专项验证已按用户决定列入后续方向。

正式 APK 使用非调试release构建，沿用当前原型签名，用于个人覆盖安装；后续更新继续保持应用标识和签名一致。发布附件提供 SHA256 校验文件，构建复现和代码入口见[开发文档](development.md)。
