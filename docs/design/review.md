## 2. 已走查结果

| 检查面 | 操作与实际结果 |
|---|---|
| 日期列表 | 首四项依次为昨天、今天 09:30、今天 14:00、今天无时分；演示时刻仅前两项过期红色 |
| 顶部与滚动 | 列表滚动 220px 后表标签位置保持；表标签翻页不切换任务集合，点击标签才切表 |
| 已完成 | 行内无日期、无添加按钮、标题保持白色；取消恢复保持记录，确认恢复保留原日期 |
| 完成与删除 | 确认完成后进入已完成最上方；取消删除保持任务，确认删除后移除 |
| 无日期置顶 | 新增、取消日期、恢复无日期任务均插入最上方；原有人工排序的相对顺序保留 |
| 输入与返回 | 空标题提示填写；组件新增保存返回桌面示意，App 内新增保存回首页；多行标题可保存，组件单行展示 |
| 草稿退出 | 编辑返回出现放弃提示；继续编辑保留草稿；放弃后重开记录仍是原内容 |
| 日期精度 | 编辑显示原日期；只填小时提示补齐；2024-02-30 提示无效，2024-02-29 00:00 可预览、应用、保存并再次查看 |
| 日期取消与草稿 | 取消清除日期的确认保留原值；修改日期候选后返回出现放弃提示，放弃候选保留任务草稿原日期 |
| 清除日期提交点 | 确认清除先更新编辑草稿，保存后任务进入无日期最上方 |
| 任务排序 | 首项上移禁用；移动后返回可继续编辑草稿；保存同步组件；再新增仍保留其余任务的相对顺序 |
| 表输入与排序 | 空名、同名有提示；新增表位于末尾；重命名页显示完整长名，保存保留位置；上下移动立即更新表顺序 |
| 表删除 | 删除“工作”确认显示 20 项任务（含已完成）；取消保留表，确认删除刷新组件并选择下一张表；逐步删至一张时删除按钮禁用 |
| 空态与菜单 | 长表名在标签中省略；空表显示对应子表空态；有日期空菜单仍可打开，说明暂无可用操作 |
| 长确认正文 | 超长任务标题触发确认时，正文区域独立滚动，底部操作按钮仍完整可见 |
| 布局 | 1440、1000、390、360px 浏览器宽度下页面与工具区无横向溢出；320px 发现工具区溢出，调整后复核通过。1440px 画板上日期页“不设置日期”与确认日期按钮均完整可见 |
| 静态检查 | HTML 内脚本语法通过；9 份有效 Markdown 中 116 处本地链接均可定位（含设计产物和经验入口）；原需求 R01–R75、扩展 E01–E14 完整 |
